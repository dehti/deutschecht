# DeutschEcht

Персональный сайт преподавателя немецкого языка для украиноязычных людей в Германии.

## Публикация через GitHub Pages

1. Создай новый публичный репозиторий `deutschecht` на GitHub.
2. Загрузи в него содержимое этой папки.
3. В репозитории открой **Settings → Pages**.
4. В поле **Source** выбери **Deploy from a branch**, затем ветку `main` и папку `/(root)`.
5. GitHub покажет публичную ссылку вида `https://<username>.github.io/deutschecht/`.

Позже в тех же настройках можно подключить собственный домен.

## Структура

`index.html` — главная страница; `assets/` — логотип и фото; `images/` — будущие изображения; `css/` и `js/` — место для выделения стилей и скриптов по мере развития сайта.

## Аналитика (Google Analytics 4)

Сайт подготовлен для аналитики с предварительным согласием посетителя. Пока идентификатор не указан, никаких запросов в Google Analytics не отправляется.

1. Открой [Google Analytics](https://analytics.google.com/), создай ресурс для сайта и выбери веб-поток данных.
2. Укажи адрес сайта: `https://dehti.github.io/deutschecht/` (или свой домен, если подключишь его позже).
3. Скопируй **Measurement ID** формата `G-XXXXXXXXXX`.
4. В файле `assets/analytics.js` вставь его вместо пустого значения в строке `window.DEUTSCHECHT_ANALYTICS_ID = ''`.
5. Сохрани изменение и загрузи его на GitHub Pages.

После согласия посетителя Analytics будет считать посещения и источники переходов, а также события: просмотр раздела, переход по внешней ссылке (Instagram, TikTok, Telegram), выбор темы, ответ в мини-викторине, перезапуск викторины, завершение демо-упражнения и смену языка.

Перед публикацией заполни в `datenschutz.html` имя, адрес и e-mail ответственного за сайт. На сайте уже есть баннер согласия и кнопка для изменения выбора.
