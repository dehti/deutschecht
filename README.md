# DeutschEcht

Персональный сайт преподавателя немецкого языка для украиноязычных людей в Германии.

## Публикация через GitHub Pages

1. Создай новый публичный репозиторий `deutschecht` на GitHub.
2. Загрузи в него содержимое этой папки.
3. В репозитории открой **Settings → Pages**.
4. В поле **Source** выбери **Deploy from a branch**, затем ветку `main` и папку `/(root)`.
5. GitHub покажет публичную ссылку вида `https://<username>.github.io/deutschecht/`.

Позже в тех же настройках можно подключить собственный домен.

## Структура

`index.html` — главная страница; `assets/` — логотип и фото; `images/` — будущие изображения; `css/` и `js/` — место для выделения стилей и скриптов по мере развития сайта.
